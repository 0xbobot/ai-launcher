# 七仔 Live2D 模型制作路线研究（2026-10-04）

> 前提：小流星形象（圆绒脑袋/大眼睛/绒身体/手脚清晰/金色尾巴），**非人形**，结构简单；
> 现有素材是 AI 生成的平面 PNG（已抠图），**无分层 PSD**——这是关键卡点；
> 用途：Launcher 首页 + 未来浮窗；个人项目（Live2D 免费额度内）；
> 动作需求：待机（呼吸/眨眼/尾巴物理）+ 6 个基础动作（挥手/开心跳/睡觉/撑伞/递东西/点头）。

## 路线 A：找绑定师做

- **去哪找**：米画师（mihuashi.com，发需求单，平台担保交易）/ 淘宝（搜"Live2D建模"）/
  B站·小红书·微博（私信建模师）/ QQ群（Live2D创作者群、虚拟主播群）/ VTube Studio Discord 社群。
- **价格（2026 年行情）**：行业通用报价——基础表情角色 500–2000 元；全动作角色 2000–8000 元；
  游戏/虚拟人级 8000–50000 元。七仔是非人形 Q 版吉祥物（无口型同步、无复杂面部 XY），
  落在下限区间：**纯绑定约 800–2500 元；含拆件（从平面 PNG 分层）+500–1500 元，合计约 1500–3500 元**。
  6 个定制动作按"全动作"档计，取中段即 2000–3500 元是合理预算。
- **材料**：分层原画是卡点，三选一——
  (1) 画师按 Live2D 规范重画分层（最贵最稳）；
  (2) 绑定师从平面 PNG 拆件（部分绑定师接，拆件费另计；遮挡部位如眼睑内侧、脖子需补画）；
  (3) 用现有 AI PNG + 绑定师补画遮挡。推荐 (2)，七仔结构简单，拆件工作量小。
- **周期**：纯工作 1–3 周；热门绑定师排单 1–2 个月，总计 3–8 周。
- **交付物**：`.moc3` + `.model3.json` + `.cdi3.json` + 纹理 PNG + `.cmo3`（可编辑工程）+
  `.motion3.json` 动作文件 ×6 + 表情文件。

## 路线 B：AI 辅助绑定

2026 年工具链（均为近几个月发布，快速成熟中）：

1. **inkinesis**（codewayco，2026-09，Apache-2.0）：单张插画 → AI 自动分层（See-through 语义分解）
   → 自动绑定 → 导出 Live2D 包（`.moc3`/`.model3.json`/`.cmo3`/纹理），27/27 通过官方 Cubism Core 校验，
   单次约 4 分钟。**官方声明校验只保证技术兼容、不保证视觉质量**——需人工审查。
2. **live2d-agent-kit**（ariakage，MIT+GPL-3.0）：为 coding agent 设计的工作流，从参考图/分层 PSD 起步，
   psd2live 导出 + 官方 Core 校验。我这类 AI agent 可直接按流程执行。
3. **image2live2d**（Wzhang3912，Apache-2.0）：输入要求**已分层的图层** → 自动绑定。
4. **psd2live**：MCP server，agent 可调用做绑定/参数编辑。

- **能不能从平面 PNG 起步**：能。inkinesis 的分解步骤就是干这个的（语义分层 + 遮挡补画）。
  但遮挡补画质量是最大不确定点（七仔的尾巴根部、脚底等）。
- **我能不能直接跑通**：部分能。分解步骤**必须 GPU**（本地 NVIDIA CUDA / Apple Silicon MPS /
  远程 H100 桥接，CPU-only 不支持），我的 VM 是纯 CPU，本地跑不通。现实路径是租云 GPU
  （如 AutoDL 4090 约 ¥2–5/小时）或走远程 H100 桥接；另需 Anthropic + OpenAI API key（按量付费）。
- **动作库缺口**：AI 路线解决"绑定 + 基础参数"，6 个定制动作（撑伞/递东西等）**仍需人工在
  Cubism Editor 里 K 帧**，AI 不直接生成高质量定制动作。

## 对比

| 维度 | A：找绑定师 | B：AI 辅助绑定 |
|---|---|---|
| 费用 | 2000–3500 元（2026 行情，含拆件+6 动作） | ~0–200 元（GPU 租赁 + API 调用） |
| 周期 | 3–8 周（含排单；纯工作 1–3 周） | 1–3 天（搭环境 + 跑通 + 调优） |
| 质量 | 高：人工网格 + 物理调优，动作自然，达到"仿真"要求 | 中：技术兼容 OK，视觉需人工审查；物理/细节弱于人工 |
| 风险 | 排单不确定、沟通成本、风格还原度 | 分解补画质量不确定；定制动作仍需人工 K 帧；工具链新（2026-09 发布），坑多 |
| 交付完整度 | 全：模型 + 6 动作 + 表情 | 模型 + 基础参数；动作库需另做 |

## 推荐

**B 先行验证（1–2 天出 MVP，验证整条渲染链路），同时 A 在米画师发单锁定高品质版并行推进**——
七仔非人形结构简单，AI 成功率高、零成本快速验证；若 AI 版视觉达标可直接省掉 2000–3500 元，
不达标则人工版 3–8 周后兜底，两边不互相阻塞。
