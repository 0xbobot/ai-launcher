# 玻璃试点批落地记录（v0.68.94）

设计依据：`docs/GLASS_DESIGN.md` v0.2（参数与分级以其为准）。本文件只记落地事实与偏差。

## 范围

- Dock（强玻璃）、七仔说话气泡（强玻璃）、TODAY 卡（中玻璃）。
- 意图胶囊/结果条、扇形不在本批。
- 只换材质渲染：不改任何元素的尺寸、位置、层级与槽位。

## 路线与选型（对设计文档的两处落地修正）

1. **壁纸先内绘化**：文档 §7 假设「壁纸为内绘」，实际代码是系统壁纸透出
   （`themes.xml` 的 `windowShowWallpaper=true`），任何捕获方案都看不见它。
   本批先把系统壁纸读出来内绘到桌面最底层（`ui/glass/WallpaperBackdrop.kt`），
   与原有罩纱一起作为背景源；读不到（动态壁纸/厂商限制）时不绘制，系统壁纸
   照常透出，玻璃按纸面轻霜档工作。
2. **中玻璃不用 Haze，强/中统一自研引擎**：Haze 的样式只有模糊/叠色/噪点，
   没有饱和度控制，做不到文档标定的增色 130–140%；且其核心价值（捕获基建）
   在壁纸内绘化之后不再独有。自研引擎一套捕获两档参数，零新增依赖：
   背景源录为一个 GraphicsLayer，玻璃面按窗口位置裁补丁，施加
   RenderEffect 链（饱和矩阵 → 模糊）+ 叠色 + 顶部亮边；强玻璃再叠一层
   AGSL（`GlassShader.kt`：圆角矩形 SDF 边缘带折射 + 方向性镜面高光，
   中心零位移）。思路参考 Kyant Backdrop 的 SDF lens，未引其库。

| 档位×背景 | 模糊 | 饱和 | 叠白 | 折射 | 高光 | 亮边(顶) |

背景分类：壁纸 24×24 缩略图的亮度标准差与平均饱和度（纯逻辑）——
照片判 TEXTURED 全开；纯色/近纯色判 FLAT 自动降轻霜（强度随背景走）。

## 降级链（GlassPolicy.resolveTier，纯逻辑可测）

- API < 31 → 模拟档（现状半透明，逐像素一致）。
- API 31/32 → 强玻璃面降中玻璃（无 RuntimeShader）。
- 低内存设备降一格；省电模式或低电量（≤15% 且未充电）再降一格。
- 桌面不可见（非 RESUMED 或 D3 全屏层打开）→ 全部模拟档（只在桌面可见时启用）。
- AGSL 运行时编译失败（个别驱动）→ 强玻璃自动按中玻璃绘制。
- 信号在每次 onResume 刷新；玻璃面在 HomeHost 之外使用时（如气泡）无状态即模拟档。

## Dock 的一处口径说明

现状 Dock 是「无底、按压才显底」（v0.68.58）。玻璃档下 Dock 底面改为常驻玻璃面
（设计文档与原型 v4 中 Dock 本就是常驻玻璃卡），按压仍提亮叠色/高光；
模拟档保持原按压显底行为不变。
